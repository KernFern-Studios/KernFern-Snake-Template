## 🎮 What Makes This Template Special?

Unlike a regular Snake game, this project is designed to be **modified, customized, and experimented with**.

### 🐍 Gameplay Features

- **Continuous Movement:** The snake automatically moves at a consistent speed.
- **Keyboard Controls:** Supports arrow keys and WASD.
- **Food Collection:** Grow longer by collecting food.
- **Score Tracking:** Earn points and beat your high score.
- **Collision Detection:** Avoid walls and your own body.
- **Pause & Restart:** Control when your game runs.
- **Chrome Popup Support:** Play directly from your browser toolbar.

## 🚀 Installing Your Customized Extension

1. Download or clone the repository.
2. Extract the files if necessary.
3. Open Chrome and visit `chrome://extensions`.
4. Enable **Developer mode**.
5. Select **Load unpacked**.
6. Choose the folder containing `manifest.json`.
7. Pin the extension to your toolbar.
8. Click its icon and enjoy!

**Tip:** After editing the extension files, click the reload button on its card at `chrome://extensions` to apply your changes.

## ❓ Frequently Asked Questions

**Do I need programming experience?**

Not necessarily! The customization guides explain where to start. More advanced changes may require basic HTML, CSS, or JavaScript knowledge.

**Does the extension require an internet connection?**

The included game is designed to run locally inside Chrome.

**Do I need to publish it to the Chrome Web Store?**

No! You can install it locally using Developer mode.

**Can I change the gameplay?**

Yes! You can edit the JavaScript files to experiment with new mechanics.

**Can I share my own version?**

Check the repository's licensing and copyright permissions before redistributing modified versions.
