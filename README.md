# 🐍 KernFern Snake Template

A **fully customizable Snake game template** for Google Chrome extensions!

Made by **KernFern Studios** 🌱

## 🎮 Features

- 🐍 Smooth, continuous snake movement
- ⌨️ Arrow key and WASD controls
- 🍎 Food, scoring, and high scores
- ⏸️ Pause, restart, and game-over detection
- 🎨 Customizable colors, speed, sounds, and more
- 📖 Beginner-friendly customization guides
- 🧩 Play directly inside the Chrome extension popup!

## 📦 Installation

1. Click **Code → Download ZIP**.
2. Extract the ZIP file.
3. Open `chrome://extensions` in Chrome.
4. Enable **Developer mode**.
5. Click **Load unpacked**.
6. Select the folder containing `manifest.json`.
7. Pin the extension and start playing!

## 🛠️ Customization

| File | What It Does |
|---|---|
| `settings.js` | Game settings and customization |
| `popup.js` | Snake gameplay and controls |
| `popup.css` | Appearance and layout |
| `popup.html` | Popup interface |
| `manifest.json` | Extension information |

Read `CUSTOMIZATION-GUIDE.md` for detailed instructions!

## 🐍 How to Play

Use **arrow keys or WASD** to guide your snake. Eat food to grow and score points, but avoid walls and your own tail!
